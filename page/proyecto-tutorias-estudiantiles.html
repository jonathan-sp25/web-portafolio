JSP

Tutorías estudiantiles

Descripción:

Plataforma web desarrollada para conectar estudiantes universitarios con alumnos de ciclos avanzados o profesores, permitiendo recibir asesorías académicas en diferentes materias de manera rápida y organizada.

Tipo:

Proyecto colaborativo

Backend desarrollado en Java, implementando la lógica de negocio, autenticación de usuarios y gestión de asesorías académicas.

Frontend desarrollado con HTML, CSS y JavaScript puro, creando una interfaz moderna, responsive y fácil de utilizar.

Arquitectura monolítica integrada con base de datos MySQL para el almacenamiento y administración de la información.

Proyecto desplegado en un servidor VPS, garantizando acceso remoto, estabilidad y disponibilidad de la plataforma.

Permite agendar asesorías académicas entre estudiantes y tutores.

Los tutores pueden registrar y actualizar sus horarios de disponibilidad.

Los usuarios pueden actualizar la información de su perfil de tutor.

Los tutores pueden aceptar o gestionar solicitudes de asesoría.

Los estudiantes pueden describir sus dudas o problemas académicos antes de reservar una asesoría.
