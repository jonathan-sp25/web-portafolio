Salidas grupales

Descripción:

Plataforma web enfocada en la organización de salidas grupales, permitiendo conectar personas con gustos e intereses similares para participar en actividades sociales y recreativas.

Tipo:

Proyecto colaborativo

Arquitectura y Stack Tecnológico

Backend desarrollado en PHP mediante una arquitectura basada en API para la gestión de usuarios, salidas grupales y foros.

Frontend desarrollado con HTML, CSS y JavaScript puro, ofreciendo una interfaz dinámica, responsive y sencilla de usar.

Integración entre frontend y backend mediante consumo de API, permitiendo la comunicación y gestión de datos en tiempo real.

Aplicación desplegada en un hosting compartido, optimizando recursos y accesibilidad para los usuarios.

Funcionalidades Destacadas

Permite crear y organizar salidas grupales según intereses comunes.

Los usuarios pueden aceptar o rechazar invitaciones a salidas.

Permite editar y personalizar el perfil de usuario.

Incluye un sistema de foros para compartir publicaciones e interacciones.

Los usuarios pueden enviar solicitudes para unirse a otras salidas grupales.
