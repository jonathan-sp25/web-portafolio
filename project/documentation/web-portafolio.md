# Funcionalidades

El portafolio contará con una funcionalidad que permitirá verificar la disponibilidad de conexión con un servidor de hosting compartido.
En caso de que la conexión esté activa, se mostrará un botón de “Ver demo” que permitirá acceder a la demostración del proyecto.
Si el servidor no se encuentra disponible, dicho botón será ocultado y únicamente se mostrará el botón de “Ver detalle”.

# Despliegue

Para el despliegue del portafolio se utilizarán las siguientes tecnologías:

GitHub Pages: se empleará para alojar la parte estática del portafolio.
InfinityFree: se utilizará para alojar tres páginas que contendrán las APIs necesarias para las demos, permitiendo mantener URLs limpias y organizadas.
